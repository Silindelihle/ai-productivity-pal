# AI Productivity Pal

Create a modern, responsive frontend-only web application called AI Workplace Productivity Assistant.

Important Technical Requirements

Do NOT create a backend.

Do NOT add authentication, login, registration, user accounts, or password functionality.

Do NOT use a database.

Keep the project simple and suitable for a free Lovable account.

Build a polished frontend prototype with interactive UI elements and sample/mock AI responses where needed.

Purpose

The application helps professionals improve workplace productivity using AI tools for writing emails, researching information, and getting workplace assistance.

Design Style

Create a clean, modern, professional SaaS-style interface.

Use a colour palette focused on:

Soft pink

Blush pink

Lilac

Lavender

White

Use subtle gradients, rounded cards, soft shadows, clean typography, modern icons, and plenty of whitespace. The design should feel professional, elegant, and easy to use.

Layout

Create:

A responsive sidebar navigation on desktop.

A mobile-friendly navigation/menu for smaller screens.

A main dashboard area with a welcoming heading and overview cards.

Sidebar navigation items:

Dashboard

Smart Email Generator

AI Research Assistant

AI Chatbot

Pages and Features

1. Dashboard

Include:

A welcome message.

A short description of the application.

Three feature cards linking to the Email Generator, Research Assistant, and AI Chatbot.

A clean overview of how the tools help improve workplace productivity.

2. Smart Email Generator

Allow users to:

Enter the purpose or details of an email.

Select a tone: Formal, Friendly, or Persuasive.

Click a “Generate Email” button.

Display a realistic sample/generated email response in an editable text area.

Include buttons such as:

Generate Email

Copy

Clear

Regenerate

3. AI Research Assistant

Allow users to enter:

A research topic, question, article text, or content to analyse.

When the user submits, display structured results including:

Summary

Key Insights

Recommendations

Make the output visually organised in separate cards or sections and editable.

Include:

Analyse

Clear

Copy Results

Use realistic mock responses to demonstrate the feature.

4. AI Workplace Chatbot

Create a modern chat interface where users can:

Type workplace-related questions.

Send messages.

View AI-style responses.

Include suggested prompts such as:

“Help me write a professional email.”

“Summarise this information.”

“Give me productivity tips.”

“Help me prepare for a meeting.”

Use sample/mock responses and make the conversation feel interactive.

Responsible AI Section

Include a visible disclaimer somewhere in the application:

“AI-generated content may not always be accurate or appropriate for every situation. Always review and verify AI-generated information before using it for professional, workplace, or important decisions.”

Responsiveness

Ensure the entire application works well on:

Desktop

Tablet

Mobile

Prioritise a clean user experience, intuitive navigation, consistent styling, and polished interactions.

The final result should look like a professional SaaS productivity platform and clearly demonstrate the value of AI in helping professionals automate everyday workplace tasks.
